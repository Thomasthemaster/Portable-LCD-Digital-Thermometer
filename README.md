# Portable LCD Digital Thermometer

A portable digital thermometer with an LCD using a **DHT11 Temperature and Humidity Sensor**.

---

### Hardware
- **Development Board:** Arduino Nano
- **Main Components:** LCD + DHT11 Temperature and Humidity Sensor
- **Software:** Arduino IDE

### Cool Features
- LCD showing Temperature & Humidity
- Temperature & Humidity Sensing
- Portability
